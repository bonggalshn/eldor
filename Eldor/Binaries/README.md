# Eldor Binaries

This directory is reserved for packaged game executables.

## To Build

1. Open `Eldor.uproject` in Unreal Engine 5.4+
2. Go to **Platforms** → **Windows** → **Package Project**
3. Select this folder as the output destination
4. The executable `Eldor.exe` will be placed here after build

## Requirements

- Windows 10/11 (64-bit)
- Unreal Engine 5.4+ for packaging
- Visual Studio 2022 for C++ compilation
